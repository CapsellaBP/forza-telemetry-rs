# 调校使用指南

## 工作流

### 1. 赛前准备

1. 启动 Forza Telemetry RS 面板
2. （可选）点"启动 HUD"打开透明浮层
3. 开一辆要调的车，在直线路段**全油门加速**到最大转速

> 保持油门 >95%（默认采样阈值）。升档、松油、最大转速下降段、静止（速度为零或车轮无滑移）时不采样。

### 2. 看曲线

控制面板的功率/扭矩曲线图会逐渐成形：
- **蓝色线** = 扭矩 (Nm)，左轴
- **红色虚线** = 功率 (kW)，右轴
- **橙色竖线** = 计算的换挡点
- **红色区域** = 最大转速区
- **灰色竖线** = 当前 RPM

HUD RPM 条上也同步显示：
- **橙色竖线** = 换挡点（峰值功率位置）
- **红色竖线** = 最大转速上界
- **白色区间** = 功率带（峰值功率的 93% 范围，可调）

### 3. 锁定曲线

采样满意后，点"**锁定曲线**"冻结。

### 4. 换挡参考

- 蓝色竖线 = 峰值功率转速；到达最大功率后档位与 RPM 条蓝色闪烁
- 临近最大转速时红色闪烁，提前量见 HUD 页"红闪提前量"

### 5. 最大转速分析

踩到最大转速后，服务端自动检测：
- **最大转速上界**（红线）：更高的确认峰值使其立即上移；持续出现更低的确认峰值时，按最近 30 次峰值的中位数逐步下移
- **最大转速下界**：振荡谷值的中位数

控制面板显示"已检测"标签即表示最大转速数据就绪。

### 6. 功率带

功率带 = 峰值功率 × 阈值（默认 93%）所覆盖的 RPM 区间。

调整阈值：
- 更高（95%+）：只看最窄的甜点区
- 更低（80%）：看更宽的可用区间

## 电动车

EV 自动识别：全油门时档位 ≤2 持续 N 帧（默认 300）判为电车。

电车上 HUD 不显示换挡线和最大转速线，RPM 条全程蓝色。

## 换车

换车后：
- 旧车的曲线数据与锁定状态自动保存
- 新车加载已有预设（如有），否则默认值
- 全新车需重新踩全油门采样

控制面板"重置曲线"按钮清空当前车数据。

## 常见问题

**Q: 功率曲线忽高忽低？**
A: 调高采样油门阈值（默认 95%）或降低 EMA 权重（1/8 或 1/16）。

**Q: 换挡点不对？**
A: 确认最大转速检测已完成（面板显示"已检测"）。最大转速区功率不参与峰值计算。

**Q: 档位偶尔跳？**
A: 服务端对档位做防抖（3 帧确认），换挡标志 11 被过滤。

**Q: HUD 不显示？**
A: 游戏必须用**无边框窗口模式**。确认 Data Out 开启且端口 5300。
